# Agent notes

- Stack: TanStack Start (React 19, file-based routes in `src/routes`), Tailwind CSS v4, shadcn/ui.
- Brand details (name, domain, emails, location) live in `src/lib/site.ts` — change them there, not in pages.
- `src/routeTree.gen.ts` is generated by the router plugin on `npm run dev` / `npm run build`; don't edit it by hand.
- Theme tokens are in `src/styles.css` (`--emerald`, `--lime`, `--ink`).
